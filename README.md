# hayaraku-react-app

Welcome to React App with electron builder.

# Installation

Please Check electron-builder.js and .yml and in electron folder should be has main.ts and tsconfig

```bash
# to setting
 npm install
# on dev to init electron
 npm run electron:build:dev
```

# Building

```bash
# to build electron app and appservr
 npm run electron:dev
# to publish app and installer exe
 npm run electron:build
```

# Caution

Now setting is just windows only.
